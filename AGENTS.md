# AGENTS.md

## Project context

This project was primarily generated by AI. Treat the codebase as untrusted until verified.

## Review guidelines

Focus on serious issues, especially:

- Authentication and authorization gaps
- Business logic bypasses
- Backend trusting client-provided userId, role, price, status, permissions, or ownership fields
- Missing server-side validation
- Data consistency, transactions, idempotency, and duplicate submission risks
- Payment, order, subscription, billing, quota, or permission state bugs
- PII leakage in logs, errors, analytics, or client responses
- Secrets committed to code
- Unsafe file upload, SSRF, XSS, SQL/NoSQL injection, command injection
- Missing tests for critical business flows
- Mock, placeholder, TODO, fake implementation, or hardcoded demo logic
- Code paths that look complete but are not wired to real services
- Deployment config that works locally but fails in production

When reviewing, provide:
- Severity: P0/P1/P2/P3
- File path and line reference
- Why it matters
- Reproduction or verification steps
- Suggested fix
- Test that should be added

Do not spend review comments on minor style issues unless they hide a real defect.
