# Fishroom split Docker deployment

This package separates the system into three Docker images:

- `fishroom-frontend:local`: static frontend service, proxies `/api/` to backend.
- `fishroom-backend:local`: Node API service.
- `fishroom-database:local`: PostgreSQL with the `app_state` table init script.

## Files

- `docker-compose.separated.yml`: production compose file.
- `.env.example`: copy to `.env` and change the database password before deployment.
- `images/*.tar`: Docker image archives generated by `docker save`.
- `db-backup/fishroom_20260428.sql`: current local database backup, optional import.

## Load images on a server

Choose image archives that match the server CPU architecture.

The included archives are currently `linux-arm64`:

```bash
docker load -i images/fishroom-frontend_20260428_linux-arm64.tar
docker load -i images/fishroom-backend_20260428_linux-arm64.tar
docker load -i images/fishroom-database_20260428_linux-arm64.tar
```

If the server is `linux-amd64` / x86_64, build the same tags on that server from
the project source package:

```bash
docker build -f deploy/frontend.Dockerfile -t fishroom-frontend:local .
docker build -f deploy/backend.Dockerfile -t fishroom-backend:local .
docker build -f deploy/database.Dockerfile -t fishroom-database:local .
```

## Configure

```bash
cp .env.example .env
```

Edit `.env`, especially:

```env
FRONTEND_PORT=8787
POSTGRES_DB=fishroom
POSTGRES_USER=fishroom
POSTGRES_PASSWORD=please_change_this_password
```

The backend database connection is configured in `docker-compose.separated.yml`
under `backend.environment`:

```yaml
PGHOST: database
PGPORT: 5432
PGDATABASE: ${POSTGRES_DB:-fishroom}
PGUSER: ${POSTGRES_USER:-fishroom}
PGPASSWORD: ${POSTGRES_PASSWORD:-fishroom_local_password}
```

## Start

```bash
docker compose -f docker-compose.separated.yml --env-file .env up -d
```

Open:

```text
http://SERVER_IP:8787
```

## Optional: import current local data

Run this after the database container is healthy:

```bash
cat db-backup/fishroom_20260428.sql | docker exec -i fishroom-database psql -U fishroom -d fishroom
```

If you changed `POSTGRES_USER` or `POSTGRES_DB` in `.env`, use those values in the command.

## Stop

```bash
docker compose -f docker-compose.separated.yml --env-file .env down
```

To delete database data as well:

```bash
docker compose -f docker-compose.separated.yml --env-file .env down -v
```
