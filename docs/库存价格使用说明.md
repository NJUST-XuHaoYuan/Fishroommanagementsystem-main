# 库存价格使用说明

适用：商品管理、库存明细、日常管理及盘库。更新后请先刷新后台页面；手机微信中可关闭页面后重新进入。

## 一、价格来源怎么看

| 价格来源 | 含义 | 修改商品默认价后 |
| --- | --- | --- |
| 跟随商品价 | 普通库存使用商品统一默认价 | 未售、未损耗、未出库且未被订单占用的鱼自动同步 |
| 单独定价 | 这条鱼有自己的售价，即使金额恰好与商品价相同也算单独定价 | 保留自己的价格 |

已售、损耗、出库或被订单占用的鱼保留原库存价格。修改商品价不会修改历史订单成交金额、收款、退款或损耗记录。解除订单占用且没有其他限制后，原来“跟随商品价”的鱼会恢复使用最新商品默认价。

## 二、统一调整某个商品的价格

1. 进入「商品管理」，找到商品，点击「编辑」。
2. 修改「销售默认价」，核对提示后保存。
3. 商品价为所有场地共用，不只作用于顶部当前场地。符合条件的跟随库存一起更新；保存成功后会提示你有权限查看的场地中同步了多少条。
4. 回到「日常管理」打开鱼详情，检查价格来源及金额。其他已经打开的设备请刷新后查看。

例：商品原价 100 元改为 120 元，跟随库存变为 120 元；某条单独定价 90 元的鱼仍为 90 元，原有订单金额不变。

## 三、只调整一条鱼

1. 在「日常管理」点击这条鱼，打开生物详情。
2. 在售价的来源选择中，将「跟随商品价」改为「单独定价」。
3. 输入金额，点击「保存信息」并确认。
4. 以后想重新跟随，选择「跟随商品价」再保存，系统会使用商品当前默认价。

价格控件置灰通常表示已售、出库、损耗或关联订单；不要为了改价随意撤销真实业务记录。仅上传养护图片、视频或修改备注时，不需要操作价格。

## 四、原来的“历史价格待确认”怎么办

本次更新取消该选项，原来这类库存统一改为「跟随商品价」，不需要工作人员一条一条点击确认。未明确单独定价的旧库存也默认跟随商品价。

- 普通未售、未损耗、未出库且未被订单占用的鱼：使用商品当前默认价，之后随商品改价。
- 已经明确设置为「单独定价」的鱼：保留自己的金额和定价方式，不受本次转换影响。
- 已售、损耗、出库或被订单占用的鱼：即使来源显示为「跟随商品价」，仍保留原库存金额；既有订单成交金额、收款、退款及损耗记录不变。解除占用且可售后，跟随库存恢复使用最新商品默认价。
- 商品缺失或没有有效默认价：暂保留原金额，不会改为 0；请先在商品管理核对并补充有效售价。

刷新后，「日常管理」的价格来源筛选只保留「全部」「跟随商品价」「单独定价」。历史审批或操作记录可能仍出现旧名称，用于保留当时的实际情况，不代表还需要逐条确认。

## 五、新入库、盘库与审批

新增库存默认「跟随商品价」；手工修改金额会切为「单独定价」。需要恢复统一价时，重新选择跟随。

原有权限和审批要求保留。审批明细会展示价格来源变化，即使金额没变，也能看到是从跟随改为单独定价。若审批期间商品价或库存信息变化，系统会阻止按过期明细执行，请管理员填写原因驳回，再由发起人核对并重新提交。

遇到「价格已变化」「页面版本过旧」等提示，请刷新、重新打开编辑窗口，核对最新价格后再保存，不要反复提交旧页面。
